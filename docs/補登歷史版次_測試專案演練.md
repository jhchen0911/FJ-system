## ⑤ 管理員確認（Lotion）

1. 管理員那個視窗回首頁：「今天要做的事」出現「補登報價版次 1 張待確認」→ 點進去。
2. 卡片上只有「退回／修改／確認」三顆。看細節：補登前 V1、V2、（存檔）、現行 V3；補登後 V1、（存檔）、**V2 新增（已送業主）**、V3（原 V2 改號）、現行 V4；檢查全部 ✓；含稅 13,125。
3. 按「修改」會跳出來源報價單畫面（正式那次拿 10/27 寄出的 PDF 比對），看完關掉。
4. 按「確認」：會下載一個「補登版次備份_DRILL-01_….json」→ 留著。
5. 自動開歷史版本：V1、V2（補登版次）、V3、現行 V4；另有一筆「補登版次前備份」。

## ⑧ 防漏（各看一次）

1. 「演練案」編輯頁改一個單價、存檔 → 匯出 PDF → 選「只匯出、不封存」：歷史版本多一筆紅色「匯出過、沒封存」。
2. 再改一次單價存檔 → 經營報表 › 資料健檢：出現「演練案：… 匯出過的 PDF（V4）沒封存，內容已經改掉了」。
3. 歷史版本 › 還原「匯出過、沒封存」那筆 → 再還原別的版本：確認視窗會寫「目前這份內容 … 匯出過、還沒封存：還原前會先封存成正式版 V4」→ 確認後歷史多一個正式 V4，健檢那一行消失。
4. 唯讀帳號匯出一次 PDF → 管理員首頁出現「代匯出的報價 1 份：要不要封存成正式版」。
