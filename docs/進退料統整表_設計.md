## 一句話

工務拍簽收單 → AI 讀 → 首頁卡片確認 → 寫進「進退料簿」（每一趟一筆）。之後台帳、租料批次、租金、退料提醒、租賃商對帳、業主逾期租金比對，都由系統照這本簿子自己算。

```
工務拍簽收單（智慧收件，已有）
   │ AI 讀欄位；讀不出的標黃
   ▼
首頁卡片「簽收單待確認」（工務＋Lotion；卡片上沒有金額）
   │ 確認
   ▼
進退料簿（新，每趟一筆）──── 金額那一半（只給 Lotion）
   ├─ 自有料 → 台帳自動改（三種情況改成卡片等 Lotion）
   ├─ 租賃料 → 租料批次自動建／結 → 租金成本
   │            ├─ 退料提醒（拔除完成還在場 > 3 天；工務看得到多付租金）
   │            ├─ 計租日期差 ≥ 1 天提醒（金額只給 Lotion）
   │            └─ 租賃商請款核對（第 6 步廠商請款卡上顯示差額）
   ├─ 轉場 → 一筆寫兩案（A 退、B 進），租期接續
   └─ 結案 → 回寫單價庫（租期、每趟運費、損耗、吊車）→ 下次報價用
```

## 一、已定案（不用再問）

| 項目 | 定案 | 來源 |
|---|---|---|
| 拍照流程 | 拍完直接進首頁卡片，拍照那一步只顯示「已收到，待確認」 | 11/05 第 1 題 |
| 業主逾期租金 | 照合約（日報拔除進度）算；進退料簿退場日只拿來比對，差超過參數天數提醒 | 11/05 第 2 題 |
| 退料提醒 | 拔除完成或階段完工，這批料還在場超過 3 天（參數）→「退料提醒」給工務＋Lotion；寫已多付租金、每天再增加多少（**這個金額工務看得到**）；超過 7 天升級成 Lotion 緊急卡；每月統整「租料閒置浪費」 | 11/05 第 3 題 |
| 計租日期 | 簽收單日期跟租賃商計租起訖差 1 天以上就提醒，「可能多算 N 天、約 NT$ X」金額只給 Lotion | 11/05 第 4 題 |
| 自有料台帳 | 確認就自動改；只有三種情況卡片等 Lotion：倉庫找不到同規格、退場比工地上多、歸倉「要修／報廢」 | 11/05 第 5 題 |
| 車型 | 跨縣市→平板；同縣市且要現場卸貨→吊板；運費累積 3 個月後依實際比價；倉庫縣市放參數、可空（豐有目前沒有倉庫） | 11/05 第 6 題 |
| 誰看什麼 | 工務看得到、拍、按確認；運費、租金、賠償、吊車費看不到（退料提醒的多付租金例外） | 需求第二節 |

## 二、資料怎麼存（工務能寫、看不到錢）

一筆拆兩半，同一個編號：

| 存哪 | 內容 | 誰讀寫 |
|---|---|---|
| `fydata/shared/matMoves/<id>`（新，逐筆同步） | 日期、方向（進場／退場／轉場）、自有或租賃、材料規格長度、支數、從哪到哪、運輸公司、車型、車號、趟數、同車編號、租賃商、批次、租賃商單號、短少／損壞、吊車有無與誰叫、照片、簽收人、歸倉狀況、AI 信心（哪欄標黃）、狀態（待確認／已確認／退回） | 工務、Lotion；規則白名單擋金額欄位；已確認的只有管理員能改 |
| `fydata/private/matMoveFin`（新） | 運費、每趟單價、運費算哪案／同車分攤、租金單價與單位、計租起訖、賠償、吊車費、套用紀錄（改了哪幾列台帳、哪個批次） | 只有管理員（＋唯讀帳號，比照台帳） |

- **套用器**（台帳、租料批次、租金）跑在**管理員裝置**：私有資料下載完跑一次，之後收到新確認再跑；冪等（內容沒變不重套，變了先撤再套）。跟現在材料位置清單同一模式。
- **舊資料**：日報裡已勾「已登錄」的簽收單 → 進退料簿標已確認、**不再動台帳**（避免扣兩次）；沒勾的 → 變成首頁待確認卡。舊租料批次沒有簽收單的不補建，只標「舊批次（無簽收單）」。舊欄位一律保留。
- **規則要改**（database.rules.json，推 main 自動發布）。

## 四、要 Lotion 決定的（能用預設的都已經用了，只剩這 4 題）

| 題 | 要決定什麼 | 建議（預設） | 理由 |
|--:|---|---|---|
| 1 | **工地直接轉場，運費預設算哪一案** | **算進場的那一案（B 案）**，卡片上可改 | 料是為 B 案載的；A 案拔除已完成、運費不該再加在 A 案成本 |
| 2 | **同一台車載兩案，運費怎麼分** | **依 M 數分**（需求寫依支數；同車常常長短不一，用 M 數比較接近實際載重） | 例：12m×20 支和 6m×20 支同車，依支數各一半，依 M 數 2：1；擇一即可，之後可改 |
| 3 | **租賃單價分段（16M 以上另一段）怎麼存** | **每個租賃商一張單價表**（規格×長度區間×單位：片／月、M／月、M／天），參數頁維護；租料批次帶入，個案可改 | 11/04 寬大核對就是依租賃商的分段單價；放在租賃商身上，換案不用重填 |
| 4 | **退料提醒、閒置浪費的「多付租金」怎麼算** | **從拔除完成日（日報）算到退場日（簽收單），× 這批租金單價**；工務看到「約多付 NT$ X、每天再加 NT$ Y」 | 照 11/05 第 3 題；拔除完成前在場是正常使用，不算浪費 |

> 其他細節（欄位、規則、遷移、卡片樣子）照第二節做，不再另外問；做到 M2 卡片時會先給畫面截圖。
