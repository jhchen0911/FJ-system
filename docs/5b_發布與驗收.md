# 改版第 5 步 5b：雲端每日提醒（Lotion 電腦操作卡）

**一句話：部署 2 支雲端程式，按一次「立即跑一次」，看「雲端每日提醒」卡每一類都 ✓ 一致。不用貼規則。**

```
① 上線（說「5b 上線」）→ ② 部署 2 支雲端程式（5 分）→ ③ 資料健檢按「立即跑一次」（2 分）→ ④ 兩週每天看一眼
```

## ② 部署（Lotion-HQ 電腦，FJ-system 資料夾）
```
git checkout main
git pull
cd functions
npm install
cd ..
firebase deploy --only functions:dailyTodos,functions:healthRunNow --project jhchen-aed9a
```
- 測試專案升級 Blaze 後，同一行把 `jhchen-aed9a` 換成 `fj-system-test` 再跑一次。

## ③ 驗收
1. 網站重新整理兩次，標題列是新版號。
2. 經營報表 › 其他報表 › 資料健檢 → 「☁ 雲端每日健檢」卡按「立即跑一次」。
3. 下面一張「☁ 雲端每日提醒（並行比對）」：六類（租期逾期、租期 7 天內到期、收款、保留款、可以確認結案、報價進版）都是「✓ 一致」就成功，截圖給陳軒。
4. 工程專案 › 業主扣款設定：保留款「退還月數」欄（條件文字裡有月數會自動帶，例「自動 12」），旁邊會寫「結案日 ＋ 12 個月＝某日」。

## 正常的「不一致」
- 這台剛改的資料還沒同步；雲端是早上 7 點的資料。
- 一般員工帳號看不到應付和材料台帳，「可以確認結案」會跟雲端不同（只看管理員的比對）。

## 兩週後
- 連續一致，就把總覽提醒換成雲端（另一批做）；在那之前總覽照舊由每台裝置自己算。
