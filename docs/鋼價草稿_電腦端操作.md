# 鋼價草稿：電腦端操作（Lotion-HQ 每月一次）

FJ v6.0.216 起，「材料買價」表會依鋼價漲跌建議 Lotion 調整買價（只建議、不自動改）。
來源以**中鋼盤價**為主，由 Lotion-HQ 每月讀中鋼新聞稿做成「鋼價草稿」上傳；**主計總處營造工程物價指數**由雲端每月自動抓，當備援。

```
中鋼公布盤價（每月）──Lotion-HQ 讀新聞稿──→ FJ「鋼價草稿」──Lotion 首頁拍板卡確認──→ 記進 FJ
                                                                          │
主計總處指數（雲端每月 8、15、25 日自動抓）──────────────────────────────┤ 中鋼沒資料時才用
                                                                          ↓
                                    買價表的規格漲跌 ≥ 5% → 首頁卡片「建議買價改成 X」（寫明用了哪個來源）
每月 16 日以後兩邊都沒有新資料 → 首頁保底卡「這個月鋼價沒有資料，請手動看一下」
```

## 一、什麼時候做

每月中鋼公布下個月（或下一季）內銷盤價之後，當天或隔天做一次。到 16 日都還沒上傳、雲端指數也沒更新，首頁會出保底卡提醒 Lotion。

## 二、去哪裡看

- 中鋼官網：https://www.csc.com.tw/ → 新聞中心（盤價公告的新聞稿）。
  - ⚠️ 主線只確認過官網首頁打得開。**盤價新聞稿的確切網址，請第一次操作時記下來，回報陳軒補進這份文件**。
  - 請用一般瀏覽器開，不要用程式大量抓取（中鋼網站不歡迎自動讀取）。
- 只看兩類：
  1. **H 型鋼**（FJ 規格 H 開頭的料，例：H300、H350、H400，都照這個漲跌）。
     - ⚠️ 中鋼主要賣鋼板、鋼捲、棒線。如果新聞稿裡**沒有 H 型鋼**，請在草稿的 note 寫「中鋼無 H 型鋼」，H 型鋼那項不要填；之後 H 開頭的規格會改用主計總處指數。要不要改看東和鋼鐵的牌價，請回報陳軒問 Lotion。
  2. **鋼板**（其他規格，例：鋼板樁 IV、覆工板，照這個漲跌）。
- 要讀的數字：**這次調整的漲跌百分比（%）**。新聞稿只寫每噸調多少元時，請換成百分比（調整金額 ÷ 調整前價格 × 100），並在 note 寫原始數字。

## 三、怎麼上傳

1. 用 Lotion-HQ 的帳號登入 FJ（https://jhchen0911.github.io/FJ-system/），等首頁載入完成。
2. 按 F12 打開「主控台（Console）」。
3. 貼上下面這段，把月份、網址、數字改成這次的，按 Enter：

```js
fySteelPriceDraft({
  ym: '2026-12',                        // 盤價適用的月份（YYYY-MM）；一季一次就填季的第一個月
  url: 'https://www.csc.com.tw/…',      // 新聞稿網址
  items: [
    { cat: 'H型鋼', pct: 2.5 },          // 漲 2.5% 寫 2.5；跌寫負數，例 -1.2；沒有就整行刪掉
    { cat: '鋼板', pct: -1.0 }
  ],
  note: '熱軋鋼板每噸 -300 元（原 25,000）'
}).then(r => console.log(r))
```

4. 看到 `{ok: true}` 就完成。看到 `{ok: false, why: …}` 照 why 改好再貼一次。
5. Lotion 會在首頁看到「中鋼盤價待確認」拍板卡：確認＝記下這個月的漲跌；修改＝改數字再記；退回＝不記。

## 四、草稿格式（給 AI 看）

| 欄位 | 必填 | 說明 |
| :-- | :-- | :-- |
| ym | ✓ | 盤價適用月份 YYYY-MM |
| items | ✓ | 至少一項：`cat` 是「H型鋼」或「鋼板」；`pct` 是漲跌百分比（數字，跌為負，絕對值要小於 50） |
| url | | 新聞稿網址 |
| note | | 原始數字、特別說明（例：中鋼無 H 型鋼） |

同一個月上傳兩次，Lotion 確認後新的取代舊的。

## 五、雲端備援（不用操作）

- 雲端程式 `steelIndexMonthly`（每月 8、15、25 日 06:55）抓主計總處「營造工程物價指數」的（四）金屬製品類月指數。
  - 資料來源：政府資料開放平臺 資料集 8246 https://data.gov.tw/dataset/8246（每月更新、XML、免費）。
  - 下載網址：https://ws.dgbas.gov.tw/001/Upload/461/relfile/11525/230553/pr0501a1m.xml
- 結果存在 FJ 私有資料 `fydata/private/steelIdx`；抓不到會記錯誤原因，保底卡上看得到。
- 指數通常晚 1～2 個月公布，所以保底卡只在指數落後超過兩個月時才算「沒有資料」。
