# 鋼價草稿：電腦端操作（Lotion-HQ 每月一次，每月 16 日 10:30）

FJ 的「材料買價」表（依材料類別填每公斤價）會依鋼價建議 Lotion 調整每公斤價，**只建議、不自動改**，Lotion 在首頁拍板卡確認後才記下。

v6.0.226 起改版（Lotion 11/10 定案）：

- **H 型鋼、鋼軌樁、鋼板樁**：看**東和鋼鐵**的 H 型鋼盤價（每次每噸漲跌多少元）。
- **覆工板**：看**中鋼**的熱軋鋼捲盤價。⚠️ 覆工板以「片」計價、每片重量沒有登錄，所以每噸金額沒辦法換算成每片價，**目前不會出覆工板的建議卡**；中鋼那一筆會記進 FJ，現在只有名稱含「板／捲」的自訂公斤類別會用到。
- **不算 %，直接用調整金額**：每噸 +300 元＝每公斤 +0.3 元，建議新買價＝現在每公斤價＋調整額。
- **主計總處營造工程物價指數**照舊由雲端每月自動抓，兩個盤價都沒資料時才用。

```
東和調價通知（新聞報導）─┐
                          ├─ Lotion-HQ 讀 → FJ「鋼價草稿」→ 首頁拍板卡「鋼價盤價」Lotion 確認 → 記進 FJ
中鋼月盤（月初公布）─────┘                                                      │
                                                                                ↓
              從填價那天之後累計（填價那個月只算公告日期在填價日之後的；下個月的盤也算）：建議買價＝現在每公斤價＋（每噸調整合計 ÷ 1000）
              累計漲跌 ≥ 5% → 首頁卡片「鋼價變了，買價表要不要調」（寫來源、網址、調整額、換算方式）
主計總處指數（雲端每月 8、15、25 日自動抓）──── 兩個盤價這個月和上個月都沒有時才用
每月 16 日以後三個來源都沒有新資料 → 首頁保底卡「這個月鋼價沒有資料，請手動看一下」
```

## 一、去哪裡看

### 1. 中鋼月盤（熱軋鋼捲，給覆工板）

- 新聞中心：https://www.csc.com.tw/CS/CSC/NC/nc.aspx
- 盤價新聞稿的網址格式：`https://www.csc.com.tw/CS/CSC/NC/neli/neli_content.aspx?newid=…`
  - 例：12 月盤（11/05 公布）https://www.csc.com.tw/CS/CSC/NC/neli/neli_content.aspx?newid=DB7BCC486FED78E4
- **月盤是月初公布**（12 月盤在 11/05 就出來了）。草稿的 `ym` 填「盤價適用的月份」（12 月盤就填 2026-12）。
- 要讀的數字：**熱軋鋼捲每噸調多少元**（例：+300）。中鋼新聞稿通常沒有調整前價格，所以不用算 %。
- 請用一般瀏覽器開，不要用程式大量抓取。

### 2. 東和鋼鐵（H 型鋼，給 H 型鋼、鋼軌樁、鋼板樁）

- ⚠️ **東和沒有公開的盤價網頁**。主線 11/10 查過：
  - 東和官網新聞頁 https://www.tunghosteel.com/about/news 只有公司新聞（得獎、永續報告書、員工持股），沒有盤價公告。
  - 東和的調價是**發給下游客戶的通知**，再由財經媒體報導。例：工商時報、經濟日報的「東和鋼鐵型鋼每噸調漲 400 元」這類新聞。
  - 東和調價**不一定一個月一次**，2026 年上半年一個月就有好幾次。所以同一個月可以上傳好幾筆，每筆寫公告日期。
- 讀法：搜尋「東和鋼鐵 型鋼 盤價」或「東鋼 H型鋼 每噸」，找最近一個月的新聞，讀出**每噸調多少元、哪一天公告**，記下新聞網址。
- **固定可查的網址還沒找到**：請 HQ 第一次操作時記下用了哪個網站、哪個網址，回報陳軒補進這份文件。不要用猜的網址。
- 找不到這個月的東和調價新聞：H 型鋼那一項不要填，在 note 寫「東和本月沒查到調價」。

## 二、怎麼上傳

1. 用 Lotion-HQ 的帳號登入 FJ（https://jhchen0911.github.io/FJ-system/），等首頁載入完成。
2. 按 F12 打開「主控台（Console）」。
3. 貼上下面這段，把月份、數字、日期、網址改成這次的，按 Enter：

```js
fySteelPriceDraft({
  ym: '2026-12',
  items: [
    { cat: 'H型鋼',   perTon: 400, src: '東和鋼鐵', date: '2026-11-12', url: 'https://（新聞網址）' },
    { cat: '熱軋鋼捲', perTon: 300, src: '中鋼',     date: '2026-11-05', url: 'https://www.csc.com.tw/CS/CSC/NC/neli/neli_content.aspx?newid=DB7BCC486FED78E4' }
  ],
  note: '中鋼 12 月盤：熱軋、冷軋、鍍鋅鋼捲每噸 +300'
}).then(r => console.log(r))
```

4. 看到 `{ok: true}` 就完成。看到 `{ok: false, why: …}` 照 why 改好再貼一次。
5. Lotion 會在首頁看到「鋼價盤價（AI 讀的）」拍板卡，有三個選擇：
   - 確認＝記下這次的調整。
   - 修改＝改數字再記。
   - 退回＝不記。

## 三、草稿格式（給 AI 看）

| 欄位 | 必填 | 說明 |
| :-- | :-- | :-- |
| ym | ✓ | 盤價適用月份 YYYY-MM |
| items | ✓ | 至少一項 |
| items[].cat | ✓ | 下面四種之一：<br>「H型鋼」「鋼軌」「鋼板樁」算東和那一線（線 H）<br>「熱軋鋼捲」「鋼板」算中鋼那一線（線 P） |
| items[].perTon | ✓（或 pct） | 每噸調整金額（元），跌寫負數，絕對值要小於 20000 |
| items[].pct | | 舊格式：漲跌 %，沒有每噸金額才用 |
| items[].src | | 來源，例「東和鋼鐵」「中鋼」。沒填：H 線＝東和鋼鐵、P 線＝中鋼 |
| items[].date | | 公告日期 YYYY-MM-DD |
| items[].url | | 新聞稿或報導網址 |
| note | | 原始數字、特別說明 |

同一個月可以上傳好幾次。每噸調整金額會累加進這個月；同一天、同金額、同來源的只算一次，**所以每噸金額一定要寫公告日期 date**（沒寫日期的不會合併，重複上傳會算兩次）。金額寫錯要更正：請在卡片按「退回」再重送，不要確認兩次。舊格式的漲跌 % 則是新的取代舊的。

同一個月又調一次（例如東和月中再漲），確認過的「鋼價變了」卡會再出來一次。

## 四、雲端備援（不用操作）

- 雲端程式 `steelIndexMonthly`（每月 8、15、25 日 06:55）抓主計總處「營造工程物價指數」的（四）金屬製品類月指數。
  - 資料來源：政府資料開放平臺 資料集 8246 https://data.gov.tw/dataset/8246（每月更新、XML、免費）。
  - 下載網址：https://ws.dgbas.gov.tw/001/Upload/461/relfile/11525/230553/pr0501a1m.xml
- 結果存在 FJ 私有資料 `fydata/private/steelIdx`；抓不到會記下錯誤原因，保底卡上看得到。
- 指數通常晚 1～2 個月公布，所以保底卡只在指數落後超過兩個月時才算「沒有資料」。
