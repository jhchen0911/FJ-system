## 六、怎麼驗

- 合成樣本 (a)：每個代號至少一筆假資料，同一個 PR 用 `--update` 更新答案，commit 寫明哪幾筆、為什麼。
- 黃金樣本 (b)：Lotion-HQ 用同一份凍結快照跑；差異類別只能是 A1～A6、B1～B6 對應的「股東報表年度數字」「專案毛利」「報價淨利」等，其餘 0 筆。另附 `expect3b.js`：在快照上預先算出「哪幾案、哪個欄位會變」，HQ 只回報筆數。
