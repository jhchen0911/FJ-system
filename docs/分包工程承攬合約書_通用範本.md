# 工程承攬合約書（分包通用範本）

> 來源：業主端工程承攬合約範本的條款結構（原件為業主與本公司簽訂之合約，不收錄於 repo）。
> 本範本角色對調——**甲方＝豐有工程有限公司（定作人）、乙方＝分包廠商（承攬人）**，付款、罰則、保險改成本公司發包口徑。
> 系統自動產生：工程專案 › 分包列「合約書」或 施工成本 › 承包卡「合約書」→ `openSubContractDoc(cid)`，由分包成本卡帶入工項、單價、數量、開發票、保留款，並依參數「廠商計價日／放款日」組付款辦法；罰金‰、保險分擔、管轄法院、特約條款等空格存 `P.subCt` 當公司預設。
> 條款文字改動請同步修改 `app.js` 的 `_subContractHtml`。

定作人：豐有工程有限公司（以下簡稱甲方）
承攬人：＿＿＿＿＿＿＿＿（以下簡稱乙方）

茲因甲方承攬「〔工程名稱〕」之擋土支撐相關工程，將其中部分工項委由乙方施作，雙方議定條款如下，共同遵守：

**第一條　工程名稱**：〔工程名稱〕（業主：〔業主〕）

**第二條　工程地點**：〔工程地點〕

**第三條　承攬項目**：〔承攬項目摘要；空白時依明細列自動列出〕

**第四條　工程範圍**：乙方應依甲方提供之施工圖說、施工估價單及甲方工地人員之指示負責施工。除本合約註明由甲方提供之材料外，施工所需人工、機具、工具、設備運輸、安全衛生設施及一切費用均由乙方自理；乙方所僱人員之勞動條件、保險、工資及意外事故概由乙方負責。簽約後無論工料物價如何波動，乙方不得藉故要求加價。

**第五條　承攬內容及單價**：依下表實作實算（單價未稅）：

| 項次 | 工程項目 | 單位 | 數量 | 單價 | 複價 |
|---|---|---|---|---|---|
| 〔由分包成本卡明細列帶入〕 | | | | | |
| | | | | 預估承攬總價（未稅） | |

以上數量為預估，實際以甲方會同乙方現場計價之數量為準；單價於合約期間固定不變。

**第六條　付款辦法**：依實作數量按月計價：乙方應會同甲方工地人員辦理計價後，於每月〔廠商計價日〕日前檢附估驗請款單〔及統一發票〕向甲方請款，甲方於〔次月〕〔放款日〕日放款〔（N% 現金匯款、N% 開立 N 天期票）〕。〔每期工程款保留 N% 作為保留款，於工程全部完成（含拆除、拔除、場地清理）且經甲方驗收後無息退還。／依業主退還甲方保留款之時點，於收到後 7 日內無息退還。〕〔工程款含 5% 營業稅，乙方應開立統一發票。／本工程款不含營業稅，乙方以收據請款。〕〔付款補充〕

**第七條　工程期限**：乙方應於甲方通知之日期進場施工〔（預定進場日）〕〔，工期補充〕；各階段進度須依甲方指定之日期進場、完工，並配合本工地其他工種之施工進度，不得無故停工或延誤。

**第八條　逾期罰款**：乙方如無故不進場、未依甲方指定進度施作或逾期完工，每逾一日應給付甲方承攬總價千分之〔0.3〕之違約金，甲方得自當期或任一期工程款中逕行扣抵。

**第九條　安全衛生及環保**：乙方應督導所僱人員遵守職業安全衛生法令、本工地安全衛生規定及環保法令，並自備個人防護具。如因乙方或其人員違反前述規定致甲方或業主遭主管機關裁罰，罰鍰及衍生損失由乙方負擔，甲方得自工程款中直接扣除。業主依其工地安全衛生罰則對乙方人員所開立之罰款，由乙方負擔，甲方得自當期工程款扣除。

**第十條　工程保險**：乙方所僱施工人員均應投保勞工保險及團體意外險，施工期間所生之人員傷亡與財物損失概由乙方負責。〔本工地營造綜合保險由甲方投保，乙方分擔保險費新臺幣＿＿元整，同意由甲方於乙方第一期工程款中扣除。／本工地營造綜合保險由甲方投保；乙方施工所生之事故仍由乙方負完全責任。〕

**第十一條　清潔責任**：乙方每日收工前應將當日施工所生之殘料、廢棄物清理乾淨並運離工地；未清理者甲方得僱工代為處理，費用自乙方工程款中優先扣除，乙方不得異議。

**第十二條　工程變更**：甲方得視實際需要變更或增減工程數量，增減部分依本合約單價計算；本合約未列之新增項目，由雙方另行議價書面確認後施作。

**第十三條　終止承攬**：乙方有下列情事之一者，甲方得終止或解除本合約，並將未完成部分另行發包，乙方不得異議，其所生之差價及損失由乙方負擔：（一）無故停工或逾期達七日以上；（二）施工品質不良經甲方通知仍未改善；（三）違反安全衛生規定情節重大；（四）將本工程轉包他人。

**第十四條　保固責任**：乙方施工若致鄰房、既有結構或他人財物受損，應負修繕賠償責任並配合甲方處理；若乙方於施工前已以書面告知危害因素而甲方仍指示施作者，責任由甲方負擔。〔保固補充〕

**〔第十五條　特約條款〕**：〔有填才出現〕

**第十五／十六條　通知及送達**：雙方通知事項均以書面依本合約所載地址為之，地址變更應即以書面通知他方；因未通知致無法送達或遭拒收者，以第一次投遞日視為送達。

**第十六／十七條　爭議處理**：因本合約所生爭議，雙方應先誠信協商；協商不成時，同意以〔臺灣新北地方法院〕為第一審管轄法院。協商或訴訟期間，乙方不得藉故停工或延誤進度。

**第十七／十八條　合約效力**：本合約附件（施工估價單、施工圖說）與本約具同等效力。本合約正本一式二份，雙方各執一份為憑；未盡事宜依民法及營造業一般慣例辦理，雙方得另訂補充條款作為本約附件。
