# 改版第 5 步 5c：每月請款、超支、付包商款核對（Lotion 電腦操作卡）

**一句話：跟 5b 同兩支雲端程式重新部署一次；資料健檢「雲端每日提醒」卡多兩類比對。不用貼規則。**

## 部署（5b 上線後、或跟 5b 一起）
```
git checkout main
git pull
cd functions
npm install
cd ..
firebase deploy --only functions:dailyTodos,functions:healthRunNow --project jhchen-aed9a
```

## 驗收
1. 資料健檢 › 「立即跑一次」→「雲端每日提醒」卡多了「本月要請款」「超支」兩列，都 ✓ 一致。
2. 總覽：
   - 「本月要請款：某案（N 天後截止）」：截止日照專案的業主付款條件「每月幾日截止」（沒填用客戶資料、再沒有用 25 日）；截止前 5 天才出現，這一期開過單就消失。下面列上次開單後日報做了多少（開下一期時照日報帶入）。
   - 「超支提醒」：工項實際成本超過報價成本 10%（只提醒、不改單價庫）。
   - 「付包商款待核准 N 筆」：點進去看核對表（日報量、廠商累計請款、業主已請、背對背條件），按「核准」記下你核准的時間；之後照常到應付付款。
3. 一般員工帳號看不到成本與應付，不會出現超支與付包商款這兩類（正常）。
