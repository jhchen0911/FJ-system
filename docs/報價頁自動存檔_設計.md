# 報價頁自動存檔：設計（第 7 步線，2026-11-11，等 Lotion 定案）

一句話：報價編輯頁改完 3 秒自動存，**只存這台改過的欄位**，跨裝置照現有的「三方合併」處理；同一欄位兩台都改了才出「同步衝突」卡讓 Lotion 選。報價編號重號沿用現有檢查。「儲存」按鈕先並排兩週，再拿掉。

```
改了一格 ──3 秒沒再動──▶ 自動存檔
                         │
                         ├─ 跟上次存的一樣 → 不存（不多傳雲端）
                         ├─ 驗證沒過（數量負數等）→ 不存，標題列小字「沒存：原因」
                         └─ 存：只寫這台改過的欄位
                                │
                                ├─ 雲端這段時間沒人改 → 照常
                                ├─ 別台改的是別的欄位 → 兩邊自動合併
                                └─ 別台也改了同一欄 → 先用較新的、出「同步衝突」卡
```

## 現在的儲存（saveQ）做了什麼

1. 驗證：工程名稱必填、數量不能負數、減項列數量 > 0。
2. 衝突偵測：編輯期間雲端換成別台的新版 → 跳視窗問要不要整份覆蓋（v5.375）。
3. 用編輯頁欄位**整份**覆蓋報價（保留日報、材料等非編輯頁欄位）。
4. 新報價且編號被用過 → 自動改下一個空號＋記 `q.codeLog`（v6.0.194）。
5. 同步業務抽成、業主端佣金應付；存一份自動備份（保留最近 10 份）。

## 自動存檔怎麼做

| 項目 | 做法 | 為什麼 |
| :-- | :-- | :-- |
| 時機 | 編輯頁任何輸入停 3 秒；離開編輯頁、切到別的 App（畫面隱藏）立刻存 | 不會漏存，也不會每打一個字就傳一次 |
| 沒變不存 | 跟上次存的內容指紋一樣就跳過 | 不製造假的「修改時間」、不多傳雲端 |
| 只存改過的欄位 | 開頁時記一份編輯頁欄位的基準；存的時候只把「跟基準不一樣」的欄位寫回報價 | 別台同時改了別的欄位（例如工務在手機補了案場細節），不會被這台整份蓋掉 |
| 跨裝置同欄位 | 交給現有的三方合併（`_recMerge3`，報價本來就在 `_CF_COLLS`）：先用較新的，記成衝突 → 今天頁「同步衝突」卡選要哪一個 | 已經上線的機制，不另做一套 |
| 編輯期間被別台改過 | 原本跳視窗問「整份覆蓋？」→ 改成不問：只存改過的欄位，同欄位走衝突卡 | 自動存檔不能每 3 秒跳一次視窗 |
| 驗證沒過 | 不存；標題列（版號旁的存檔狀態）顯示「沒存：數量不能負數」 | 不加按鈕、不跳視窗 |
| 新報價 | 填了工程名稱才開始自動存（見題 A） | 沒名字的空白單不進資料庫 |
| 報價編號重號 | 第一次自動存時照現有檢查：被用過就改下一個空號＋提示＋留紀錄；兩台離線各自開同號 → 現有「報價編號重號」拍板卡（qdup）處理 | 沿用，不改規則 |
| 自動備份 | 自動存不每次都留備份：同一張 10 分鐘最多一份，正式版次照舊只在送出時封存 | 不讓 10 份自動備份被 3 秒一次洗掉 |
| 抽成／佣金應付 | 照舊每次存都重算（已是冪等） | 不變 |
| 唯讀帳號 | 不自動存（`_roDeny`） | 不變 |
| 舊選單 | 照舊手動「儲存」，不自動存 | 「每頁切回舊版」的人行為不變 |

## 影響清單（動到的地方）

- `_saveQCore`：拆成「準備內容＋驗證」與「寫入」兩段，自動存與按鈕共用；寫入改成「只寫改過的欄位」。
- 編輯頁輸入事件（`rItems`／`rTots` 之後）掛 3 秒計時；`go()` 離開 editor、`visibilitychange` 立刻存。
- 衝突視窗（v5.375）：自動存不跳；手動「儲存」並排期間照舊。
- `saveQVersion` 自動備份節流（10 分鐘）。
- 冒煙要補：打字 3 秒後存、沒變不存、驗證沒過不存＋狀態字、兩台改不同欄位都留下、同欄位出衝突卡、新報價重號自動改號、唯讀不存、舊選單不自動存；合成樣本與單據指紋應不變（只動存檔時機，不動金額）。
- 黃金樣本：只動存檔時機，數字應 151／151 一字不差。
