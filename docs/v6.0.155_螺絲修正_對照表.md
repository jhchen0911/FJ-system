# 材料估算 螺絲修正 對照表（v6.0.155，Lotion 11/03 簽核方向）

> 改前＝v6.0.153（即時預覽批），改後＝v6.0.155。同一批假資料各算一次，數字由程式直接輸出。預設案：周長 130 M、面積 1,000 ㎡（短邊 25 M、長邊 40 M）、5 層、中柱 140 支。

## Lotion 11/03 決定（陳軒轉達）

1. 對鎖 4 顆不重複（短螺絲＝總數−長螺絲）：不改。
2. 支撐接頭＝每路支數−1：簽核。
3. 千斤頂保護夾每組 16 顆短螺絲；中間樁本身不另加，柱上托支撐的三角架要算（已含在「三角架×2」）；施工構台改長螺絲＝構台面積×1 顆／㎡（取代「構台螺絲＝面積×2」）；角撐每支 10 顆照舊。
4. 「貼板」顯示名稱改「續接板」（資料欄位不變）。
5. 支撐 M 改用圖面路數：v6.0.155 之後另開一批（先出設計樣張）。

## 一、算法（改後）

| 項目 | 算法 |
|---|---|
| 圍令接頭 | 圍令長 ÷ 7（不變） |
| 支撐接頭 | Σ 路數 ×（ceil(每路長÷7) − 1）；自動路數每路長＝對邊長；雙支撐×倍數 |
| 合板 | ceil(圍令長÷7)×1 ＋ 支撐接頭×2 |
| 螺絲總數（每層） | 三角架×2 ＋ 圍令接頭×16 ＋ 支撐接頭×28 ＋ 斜撐×10 ＋ 角撐×10 ＋ **千斤頂保護夾×16（新）** |
| 長螺絲（每層） | H350／H400：（圍令接頭＋支撐接頭）×4；H300 為 0 |
| 短螺絲（每層） | 總數 − 長螺絲 |
| 長螺絲（施工構台） | **構台面積 × 1**（新；原「構台螺絲＝面積×2」刪除），叫料單列在「施工構台／欄杆／安全設施」 |
| 三角架 | 單圍令：ceil(周長÷3)＋中柱數；雙圍令：中柱數×支撐倍數（柱上托支撐的都在內）；大三角架（雙圍令周邊）不算螺絲（膨脹螺絲時另計） |

## 四、說明

- 短螺絲每層多了「千斤頂保護夾×16」（預設案 8 組×16＝128 顆），但支撐接頭變少（38.6→32），合起來預設案每層 1,877→1,847。
- 情境 D（自動路數）短螺絲變多：自動路數 8＋6 路、總長 440 M，比「面積×0.4−周長」的 270 M 多，接頭跟著多。這是下一批「支撐 M 改用圖面路數」要一起處理的口徑差。
- 情境 G：構台 200 ㎡ → 原「構台螺絲 400 顆」改為長螺絲 200 顆，併入採購清冊的長螺絲（1,010＋200＝1,210）。
- 「貼板」→「續接板」只改顯示名稱；已存進專案的舊材料估算清單保留原名稱。
