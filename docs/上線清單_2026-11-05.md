## 2. 電腦步驟（Lotion-HQ，FJ-system 資料夾）

### 2-1 Google OAuth 用戶端（約 10 分鐘，只做一次）
照 `docs/待辦同步Google工作表_授權操作卡.md` **第一部分**：在 Google Cloud 主控台建 OAuth 用戶端、登記重新導向 URI，抄下用戶端 ID 和密鑰（不要貼到對話或任何檔案）。
- 來不及做：先跳過 2-1、2-2，第 2-4 步改用「不含 Google 的部署指令」，Google 工作表之後再補。

### 2-2 設 2 個密鑰（約 2 分鐘）
```
git checkout main
git pull
firebase functions:secrets:set GTASKS_CLIENT_ID --project jhchen-aed9a
firebase functions:secrets:set GTASKS_CLIENT_SECRET --project jhchen-aed9a
```
- 每一行跑完會問值，貼上 2-1 抄下的 ID／密鑰按 Enter。

### 2-3 貼規則（約 3 分鐘，只貼一次，裡面已經合了改單草稿、5d 的新節點）
1. 開 https://raw.githubusercontent.com/jhchen0911/FJ-system/main/database.rules.json → Ctrl+A、Ctrl+C。
2. 開 https://console.firebase.google.com/project/jhchen-aed9a/database/jhchen-aed9a-default-rtdb/rules → Ctrl+A、Ctrl+V → 發布。

### 2-4 部署雲端程式（約 10 分鐘，一行）
```
cd functions
npm install
cd ..
firebase deploy --only functions:dailyTodos,functions:healthRunNow,functions:dailyReport,functions:dailyReportCatchup,functions:dailyReportNow,functions:gtasksSync,functions:gtasksSyncHourly,functions:gtasksAuthStart,functions:gtasksAuthCallback,functions:monthlySnapshot,functions:pnlSnapNow --project jhchen-aed9a
```
- 沒做 2-1／2-2 時改用（不含 Google 的 4 支）：
```
firebase deploy --only functions:dailyTodos,functions:healthRunNow,functions:dailyReport,functions:dailyReportCatchup,functions:dailyReportNow,functions:monthlySnapshot,functions:pnlSnapNow --project jhchen-aed9a
```
- 部署前會自動印「[copy-calc] 已複製 N 個計算檔」，正常。問要不要開 API 一律按 y。

### 2-5 Google 授權（約 2 分鐘，部署後）
FJ › 人員管理 › 「LINE 機器人」卡 → 按「授權 Google 工作表」→ 用自己的 Google 帳號同意（操作卡第四部分）。
