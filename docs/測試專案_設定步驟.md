# 測試專案 fj-system-test 設定步驟（手機可做）

改版第 0 步起，系統分成兩個 Firebase 專案：

```
https://jhchen0911.github.io/FJ-system/（index.html）──▶ 正式專案 jhchen-aed9a（真實資料）
beta.html、test.html、本機開檔、localhost、分支預覽 ──▶ 測試專案 fj-system-test（假資料）
```

- 判斷寫在 `app.js` 的 `_fyEnvOf`：只有「https＋jhchen0911.github.io＋/FJ-system/ 或 /FJ-system/index.html＋不是 beta」才連正式專案，其他一律連測試專案。判斷結果和實際設定對不上時，系統不連雲端（`FY_ENV_OK`）。
- 測試頁右下角有紫色「測試環境・fj-system-test」標示；beta 左下角是橙色「β 測試版・連測試專案・不上傳」。
- **beta.html**：可以登入、可以讀測試專案，**任何東西都不寫上雲端**（資料庫、Storage 在 Firebase 套件層就擋掉）。本機資料仍是第一次開啟時從正式版複製的副本。
- **test.html**（第 0 步合併後才會出現在網站上）：連測試專案、**可以寫入**，給 Lotion 在手機上測雲端流程。本機資料從空白開始，存在 `test:` 開頭的鍵，不會碰到同一支手機上正式站的資料。
- 測試專案只放假資料或去識別化複本（案名、客戶、廠商換成代號）；**不要把正式資料匯入測試專案**。

## 現在就能在手機上做的（2 步）

### 第 1 步：貼上資料庫規則（約 3 分鐘）

測試專案的規則和正式站一模一樣（同一份 `database.rules.json`），正式站之後換規則時，測試專案也要跟著換。

1. 用手機瀏覽器打開：https://raw.githubusercontent.com/jhchen0911/FJ-system/main/database.rules.json
2. 長按畫面任一處文字 → 選「全選」→「拷貝」。（整份從 `{` 開頭、`}` 結尾，約 14,000 字）
3. 打開 https://console.firebase.google.com → 點專案 **fj-system-test**。
4. 左上角選單（三條線）→ **建構（Build）** → **Realtime Database**。
5. 上方分頁點 **規則（Rules）**。
6. 點進規則編輯框 → 全選 → 刪除（框裡變空白）→ 長按 → **貼上**。
7. 按 **發布（Publish）**。看到「規則已發布」就完成。
   - 如果跳出紅字錯誤，通常是沒有複製完整（開頭不是 `{` 或結尾少了 `}`），回到第 1 小步重新複製一次。

### 第 2 步：建立測試用的登入帳號（約 3 分鐘）

1. 同一個主控台，左上角選單 → **建構（Build）** → **Authentication** → 上方分頁 **使用者（Users）**。
2. 按 **新增使用者（Add user）**：
   - 電子郵件：`jhchen0911@gmail.com`（跟正式站同一個 email，規則才會把你當擁有者）
   - 密碼：**另外想一組新的，不要跟正式站一樣**。這組只用在測試專案。
   - 按 **新增使用者**。
3. 再按一次 **新增使用者**，建一個「一般員工」測試帳號（之後測權限用）：
   - 電子郵件：`fjstaff1@example.com`
   - 密碼：另一組新的
4. 兩個帳號都出現在列表上就完成。密碼不要傳給任何人、不要貼進 LINE 或對話。

## 第 0 步合併到 main 之後才做的（會另外通知）

### 第 3 步：用測試站登入一次

1. 手機打開 https://jhchen0911.github.io/FJ-system/test.html
2. 右下角要看到紫色「測試環境・fj-system-test」。**沒看到就停下來，不要登入**，回報給陳軒。
3. 用第 2 步的 `jhchen0911@gmail.com`＋測試密碼登入。
4. 進「人員管理」，把 `fjstaff1@example.com` 加成一般員工（角色不要勾「可讀成本資料」）。

## 要 Blaze 方案、回國再做的

- 測試專案的 **Storage**（附件、照片、每日備份）和 **Cloud Functions**（附件權限、AI 代理、LINE 機器人）都要升級 Blaze 方案才能開。沒開之前，在測試站上傳附件會失敗，屬正常。
- 列在 `docs/回國後部署清單_20261031.md` 第 8 步。

## 出問題時

| 狀況 | 原因／處理 |
|---|---|
| 測試站登入顯示「帳號或密碼錯誤」 | 第 2 步建的是測試專案的帳號，密碼跟正式站不同；確認用的是測試密碼 |
| 登入後看不到任何資料 | 正常：測試專案一開始是空的 |
| 存檔時顯示權限不足 | 第 1 步規則還沒發布，或貼的不完整 |
| 測試站右下角沒有紫色標示 | 網址打錯（例如打成正式站），先關掉頁面，不要登入 |
